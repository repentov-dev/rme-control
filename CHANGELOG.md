# Changelog

All notable changes to RME Control. The version number is shown in
**Settings → About** and in the installer filename.

## 3.8

- Scrolling for the main popover when its contents overflow.
- Settings item in the context menu of the menu bar icon.

## 3.7

- Setup wizard for the first launch.
- All hotkeys are now customizable.

## 3.6

- Scan of TotalMix inputs and outputs in the Routing section.
- Fixed increased power consumption (~6 W) while TotalMix was not running: OSC
  transmission switched from `NWConnection` to a plain UDP socket.

## 3.5

- Option to mute all other outputs when switching the active output with
  Option + ↑/↓ (handy for mixing and production).

## 3.4

- Setting to choose whether changing the volume unmutes the output.
- The mute notification now shows the name of the output.
- Option + ↑/↓ quickly switches which output the volume keys control.
- Presets to save and restore all application settings.
